# Montage

Downloads voor [Montage](https://montage-mac.vercel.app), een video-studio voor je Mac die Claude Code aanstuurt.

Deze repo bevat enkel de builds. De broncode is nog gesloten en wordt open source bij versie 1.0.

**[Download de nieuwste versie](https://github.com/LoranMaes/montage-releases/releases/latest/download/Montage-arm64.dmg)** (Macs met Apple Silicon)

Montage is nog niet bij Apple geregistreerd. Open de app één keer, ga dan naar Systeeminstellingen → Privacy en beveiliging en klik op **Open toch**.
